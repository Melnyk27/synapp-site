Install TakeSync

Mac with Apple Silicon · macOS 12 or later

Please read before you open the app. TakeSync is not yet notarized by Apple, so the first time you open it macOS warns that it “could not verify TakeSync is free of malware”. That’s expected — the app is safe, works offline and never uploads your media. Step 3 shows how to allow it once; it takes under a minute.

1. Download

Download TakeSync.dmg

Open the downloaded file.

2. Move to Applications

Drag TakeSync onto the Applications folder in the window that opens.

3. Allow it to open (once)

Pick one of the two ways:

Option A (fastest): one command in Terminal

  1. Open Terminal: press ⌘ Space, type Terminal, press Return.
  2. Copy this line, paste it into Terminal and press Return:
xattr -dr com.apple.quarantine /Applications/TakeSync.app
  1. Open TakeSync from Applications as usual.

Option B: System Settings

  1. Open TakeSync from Applications. When the warning appears, click Done (not “Move to Bin”).
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the message about TakeSync and click Open Anyway.
  4. Confirm with your password or Touch ID, then click Open Anyway again.

You only need to do this once. Updates install without the warning.

Still not opening?

Write to support@takesync.uk with your macOS version and a screenshot — we usually answer within a day.

搭载 Apple 芯片的 Mac · macOS 12 或更高版本

打开应用前请先阅读。TakeSync 尚未经过 Apple 公证，因此首次打开时 macOS 会提示“无法验证 TakeSync 不含恶意软件”。这是正常现象——应用是安全的，离线运行，绝不会上传你的素材。第 3 步介绍如何允许一次，用时不到一分钟。

1. 下载

下载 TakeSync.dmg

打开下载的文件。

2. 移到“应用程序”

在打开的窗口中，把 TakeSync 拖到 应用程序 文件夹。

3. 允许打开（仅一次）

任选以下一种方式：

方式 A（最快）：在“终端”中运行一条命令

  1. 打开终端：按 ⌘ 空格，输入终端，按回车。

  1. 像平常一样从“应用程序”打开 TakeSync。

앱을 열기 전에 읽어 주세요. TakeSync는 아직 Apple의 공증을 받지 않아, 처음 열 때 macOS가 “TakeSync에 악성 코드가 없는지 확인할 수 없다”고 경고합니다. 정상입니다. 앱은 안전하며 오프라인으로 작동하고 미디어를 어디에도 업로드하지 않습니다. 3단계에서 한 번 허용하는 방법을 안내합니다. 1분도 걸리지 않습니다.

1. 다운로드

TakeSync.dmg 다운로드

다운로드한 파일을 엽니다.

2. 응용 프로그램으로 이동

열린 창에서 TakeSync를 응용 프로그램 폴더로 드래그합니다.

3. 열기 허용(한 번만)

두 가지 방법 중 하나를 선택하세요:

방법 A(가장 빠름): 터미널에서 명령 하나

  1. 터미널을 엽니다: ⌘ 스페이스를 누르고 터미널을 입력한 뒤 Return.
  2. 이 줄을 복사해 터미널에 붙여넣고 Return을 누릅니다:

  1. 평소처럼 응용 프로그램에서 TakeSync를 엽니다.

  4. 암호나 Touch ID로 확인한 뒤 다시 그래도 열기를 클릭합니다.

한 번만 하면 됩니다. 업데이트는 경고 없이 설치됩니다.
