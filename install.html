Install TakeSync

Mac with Apple Silicon · macOS 12 or later

1. Download

Download TakeSync.dmg and open it.

2. Move to Applications

Drag TakeSync onto the Applications folder in the window that opens.

3. Open it the first time — option A: System Settings

TakeSync is not yet notarized by Apple, so on the first launch macOS warns that it “could not verify TakeSync is free of malware”. The app is safe: it works offline and never uploads your media. Allow it once:

  1. Open TakeSync from Applications. When the warning appears, click Done (not “Move to Bin”).
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the message about TakeSync and click Open Anyway.
  4. Confirm with your password or Touch ID, then click Open Anyway again.

Option B: one command in Terminal

If you prefer, open Terminal (Applications → Utilities), paste this line and press Return:

xattr -dr com.apple.quarantine /Applications/TakeSync.app

Then open TakeSync normally. You only need to do this once; updates install without the warning.

Write to support@takesync.uk with your macOS version and a screenshot — we usually answer within a day.

Встановлення TakeSync

Mac з Apple Silicon · macOS 12 або новіша

1. Завантаж

Завантаж TakeSync.dmg і відкрий його.

2. Перенеси в Програми

Перетягни TakeSync на папку Applications (Програми) у вікні, що відкрилося.

3. Перший запуск — варіант A: Системні параметри

TakeSync ще не нотаризований Apple, тому при першому запуску macOS попереджає, що «не може перевірити, чи немає в TakeSync зловмисного ПЗ». Програма безпечна: працює офлайн і нікуди не надсилає твої відео. Дозволь її один раз:

  1. Відкрий TakeSync із Програм. Коли з’явиться попередження, натисни Готово (не «Перемістити в Смітник»).
  2. Відкрий Системні параметри → Приватність і безпека.
  3. Прокрути вниз до повідомлення про TakeSync і натисни Усе одно відкрити.
  4. Підтверди паролем або Touch ID і ще раз натисни Усе одно відкрити.

Варіант B: одна команда в Терміналі

Відкрий Термінал (Програми → Утиліти), встав цей рядок і натисни Return:

xattr -dr com.apple.quarantine /Applications/TakeSync.app

Потім відкривай TakeSync як звичайно. Це потрібно лише раз; оновлення ставляться без попередження.
